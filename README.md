# מרתון תל אביב 2027

אפליקציית האימונים של עמית: התוכנית ל־22 שבועות, סימון אימונים, רישום תוצאות, קצבים, ומאמן שעונה בתוך האפליקציה.

- עובדת בלי חשבון ובלי שרת. הנתונים נשמרים בטלפון בלבד.
- עובדת גם בלי אינטרנט אחרי הפתיחה הראשונה.
- גיבוי: לשונית ״תוכנית״ ← ״ייצוא גיבוי״. שחזור באותו מקום.
- המאמן בתוך האפליקציה עובד עם מפתח API אישי של Anthropic, שנשמר רק בטלפון ולא נמצא בקוד הזה. בלי מפתח, לשונית ״מאמן״ מכינה עדכון לשליחה ידנית.
- אפשר לצרף עד 6 צילומי מסך מהשעון בכל הודעה.
